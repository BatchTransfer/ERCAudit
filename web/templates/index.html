ERCAudit

Specification-guided auditing of ERC implementations. Paste a Solidity contract to check ERC-1155 batch transfers and EIP-712 / ERC-2612 signing domains against ten risk classes.

1. Choose or paste a contract

Your source is analysed in memory and deleted immediately. It is never stored or logged. Please do not submit code you are not allowed to share.

2. Findings

What ERCAudit checks

Ten risk classes, 17 rules. A finding is a violated constraint with its source location, not a proven exploit.

  • Batch transfers (ERC-1155): missing access control, address validation, array-length check, event consistency, interface (receiver) check
  • Signing domains (EIP-712, ERC-2612): R1 missing separator, R2 missing chain ID, R3 hard-coded chain ID, R4 deployed chain ID, R5 missing verifier, R6 hard-coded verifier, R7 external verifier, R8 stored separator, R9 hard-coded salt
Limits of this service

The analysis is source-level and uses a lightweight front-end without a compiler, so unusual formatting, deep inheritance and inline assembly can cause misses or false positives. Rules R4 and R7 depend on deployment values and are reported as candidates. The on-chain verification of the paper needs network access and is not part of this web service.
